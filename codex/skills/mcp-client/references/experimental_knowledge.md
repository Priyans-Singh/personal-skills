# `mcp.client.experimental`: deprecated task extension

Source inspected: MCP 1.30.0; covers `experimental/__init__.py`, `tasks.py`, `task_handlers.py`. Tasks were removed from the MCP specification and these APIs warn/deprecate toward removal in MCP 2.0. Use only against a known extension-compatible peer.

`ExperimentalClientFeatures(session)` is a no-state facade (normally `session.experimental`). `call_tool_as_task(name, arguments=None, *, ttl=60000, meta=None)` sends `tools/call` with `task: {ttl}` in integer milliseconds, expects `CreateTaskResult`, and does not check capability/tool schema. `get_task(id)` sends `tasks/get`; `get_task_result(id, result_type)` sends `tasks/result` and validates against caller's chosen result type; `list_tasks(cursor=None)` sends truthy cursor only; `cancel_task(id)` sends destructive remote `tasks/cancel` with no confirmation/retry. `poll_task(id)` immediately yields status, then sleeps server `pollInterval` ms or 500 ms until completed/failed/cancelled; input-required is nonterminal and there is no deadline/backoff/payload retrieval.

`ExperimentalTaskHandlers` is the inbound counterpart. Handler protocols are get task, get result, list, cancel, task-augmented sampling, and task-augmented elicitation. Defaults return `METHOD_NOT_FOUND` for pure tasks and `INVALID_REQUEST` for augmentation. `build_capability()` advertises custom list/cancel/augmentation handlers (overriding only get/get-result does not advertise). `handles_request` recognizes four tasks requests; `handle_request` dispatches, validates `ClientResult|ErrorData`, responds, and lets handler exceptions propagate. Custom handlers own task persistence, workers, authorization, pagination, and cancellation. With `params.task`, ClientSession bypasses ordinary sampling/elicitation callback and invokes augmented handler.

Callable index: package re-export; `ExperimentalClientFeatures.__init__`, `call_tool_as_task`, `get_task`, `get_task_result`, `list_tasks`, `cancel_task`, `poll_task`; six handler protocols, six defaults, `ExperimentalTaskHandlers.build_capability`, `handles_request`, `handle_request`.

Literal handler names: `GetTaskHandlerFnT`, `GetTaskResultHandlerFnT`, `ListTasksHandlerFnT`, `CancelTaskHandlerFnT`, `TaskAugmentedSamplingFnT`, `TaskAugmentedElicitationFnT` each defines `__call__`; defaults are `default_get_task_handler`, `default_get_task_result_handler`, `default_list_tasks_handler`, `default_cancel_task_handler`, `default_task_augmented_sampling`, `default_task_augmented_elicitation`.
