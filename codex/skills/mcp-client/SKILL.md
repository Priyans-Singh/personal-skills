# MCP Client

Use this skill for work involving the locally installed `mcp.client` package: client implementation, transport selection, async lifecycle, OAuth integration, session groups, or experimental task compatibility. It is source-grounded in MCP Python SDK 1.30.0.

## Route by concern

- Read `references/session_knowledge.md` for `ClientSession`, handshake, callbacks, tool/resource/prompt requests, timeouts, and result validation.
- Read one transport reference: `stdio_knowledge.md`, `streamable_http_knowledge.md`, `sse_knowledge.md`, or `websocket_knowledge.md`. Prefer Streamable HTTP for new remote code; WebSocket and the task API are deprecated.
- Read `references/auth_knowledge.md` for HTTPX OAuth, PKCE, token storage, dynamic registration, or client credentials/private-key JWT.
- Read `references/session_group_knowledge.md` for aggregating more than one MCP server.
- Read `references/experimental_knowledge.md` only for existing task-extension compatibility.
- Read `references/__main___knowledge.md` for the package CLI and `references/__pycache___knowledge.md` only when explaining generated bytecode artifacts.

## Working rules

- Treat the reference version as local implementation evidence, not a guarantee for other SDK versions. Inspect the installed source when a behavior not covered by the matching reference decides correctness.
- Preserve AnyIO context lifecycles: a transport yields streams, then `ClientSession` is entered, initialized, used, and closed. Do not propose protocol calls before initialization without a known server exception.
- Use Pydantic MCP models for wire fields; distinguish request/session timeouts from HTTP client timeouts. Explain errors surfaced by local code versus server-defined behavior.
- For auth, do not expose tokens or client secrets. Preserve the same-origin redirect and issuer safety constraints described in the reference.
- Do not execute remote calls merely to explain source behavior. Obtain authorization before creating, cancelling, or terminating external resources.

The bundled references are copies of the project-level `mcp-client/*_knowledge.md` guides. Update both sets when revising their source analysis.
